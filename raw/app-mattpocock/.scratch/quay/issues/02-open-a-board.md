# 02: Open a board

**What to build:** A member can open a named board, see it in the team's list, and land on three empty columns. Another member sees the same board. A blank name is refused. A board can be renamed and deleted.

**Blocked by:** 01: Sign in to an empty team

**Status:** ready-for-agent

- [x] Opening a board returns it to every member
- [x] A blank name is refused
- [x] Rename and delete work, and a deleted board is gone
- [x] The page shows To do, Doing, and Done, each empty

## Comments

Implemented in this session. The acceptance criteria above are covered by the HTTP tests and the rendered board tests.
