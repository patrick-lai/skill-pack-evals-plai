# Task prompts (verbatim from run-logs)

## video

Create a 12-15 second 1080p MP4 motion video introducing a fictional task app called Tidy: logo reveal, three feature beats, end card. Build it in code (e.g. Remotion). Deliver the MP4 and the full source with run instructions.

## app

Build a medium-sized full-stack team task board. Stack: React + TypeScript (Vite) frontend, Node + TypeScript API, SQLite. Features: email/password auth, multiple boards, tasks with title, description, status (todo/doing/done), assignee and due date, drag between columns, basic tests for API and UI. Include a README with setup and run steps. Everything must run locally with one install and one start command.

## feature

Add task comments to this app: users can add and delete their own comments on a task, comments show author and time, and each task card shows a comment count. Persist in the existing database, add API and UI tests, and keep existing tests passing.

## bugfix

Users report that when a task is moved to Done, its assignee disappears. Find the root cause, fix it, and add a regression test. Keep existing tests passing.
